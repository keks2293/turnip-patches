`Shadow Cache off` - reasons and input from `tse2-tse2`, visible/zero-pixel from `tse-tse1`;
    the two are different sessions of the same scene, hence the input column above.
`Shadow Cache on` - reasons and input from `tse2-cacheon`, visible/zero-pixel from `lrz-base`;
    the two are different sessions of the same scene, hence the input column above.
Semantics: the reason counter names are read from
`src/freedreno/registers/adreno/a7xx_perfcntrs.xml` (singular `ZERO_AREA_PRIM`,
`CLIPPED_PRIM`, `TRIVAL_REJ_PRIM`, `FACENESS_CULLED_PRIM`); the XML carries no descriptions,
so a reason is named, not explained (journal 40.2, same caveat).
